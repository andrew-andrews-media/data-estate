# Data Estate Ontology

A vocabulary for describing a data estate, and an aggregate profile of one estate described with it.

- **Namespace:** `https://w3id.org/data-estate/`, requested at w3id.org
- **Site:** https://andrew-andrews-media.github.io/data-estate/
- **Status:** a holding page; the first release is due in November 2026
- **Licence:** [CC BY 4.0](LICENSE)

Releases are generated and dated. They describe the model, and the shape of the estate it was built from, never that estate's contents.

Maintained by Andrew Andrews ([@andrew-andrews-media](https://github.com/andrew-andrews-media)).
