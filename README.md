# Data Estate Ontology

A vocabulary for describing a data estate: the repositories a person or small organisation keeps, the documents in them, and the control plane that governs them.

- **Namespace:** `https://w3id.org/data-estate/`
- **Site:** https://andrew-andrews-media.github.io/data-estate/
- **Release:** 1.0, issued 27 October 2026
- **Licence:** [CC BY 4.0](LICENSE)

| Path | What it holds |
|---|---|
| `vocab/` | The vocabulary: `vocab.ttl`, `vocab.jsonld` and its documentation |
| `scheme/` | The concept schemes, with every concept |
| `shapes/` | The rules, as SHACL: `shapes.ttl` |
| `queries/` | The competency questions, as SPARQL: `cqNN.rq` |
| `docs/` | The overview |
| `release.ttl` | A DCAT and PROV description of this release |

Every file is generated and checked before release. The releases describe the model, never the contents of the estate it was built from.

Maintained by Andrew Andrews ([@andrew-andrews-media](https://github.com/andrew-andrews-media)).
